# Fin de session

Site commercial et prototype de **Fin de session**, une automatisation qui transforme un fichier Excel en certificats de réalisation Word et PDF pour les petits organismes de formation.

## Offre

- Cible : organismes de formation de 1 à 3 personnes
- Résultat : un Word et un PDF par participant
- Prix : 490 € HT, paiement unique
- Délai annoncé : 7 jours
- Contact commercial : [profil ComeUp d'Arthur Bey](https://comeup.com/fr/@arthurbey)

## Structure

- `dist/` : site statique prêt à publier
- `dist/demo/` : exemple PDF, aperçu et fichier Excel téléchargeables
- `prototype/` : générateur Python, données d'exemple et documents produits
- `docs/` : cadrage commercial et notes de reprise
- `CLAUDE.md` : contexte de travail pour Claude ou tout autre agent

## Voir le site localement

Servir le dossier `dist` avec n'importe quel serveur statique, puis ouvrir la page d'accueil.
